# ArduinoX86 Fritzing Parts

## Files

- `80C286_DIP68.fzpz` - ChipQuik PLCC68-to-DIP68 adapter
- `Intel_287XL_DIP40.fzpz` - Intel 80287 footprint (Not XL specific really)
- `82C284_DIP18.fzpz` - Intel 82284 clock generator footprint
- `82C288_DIP20.fzpz` - Intel 82288 bus controller footprint

## Import

Import the `.fzpz` files in Fritzing from the dropdown at the upper-right of the parts bin interface.
